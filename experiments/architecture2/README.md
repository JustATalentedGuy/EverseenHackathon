# Architecture 2 experiment outputs

Generated by scripts in `scripts/architecture2/`.

- `wildtrack_summary.json` — clean WILDTRACK metrics plus scenario aggregates.
- `wildtrack_noise_sweep.csv` — per-seed calibration/timestamp/detection noise results.
- `wildtrack_projection_by_camera.csv` — clean projection error by camera.
- `wildtrack_fusion_threshold_sweep.csv` — clean geometry-fusion threshold sensitivity.
- `physicalai_scene_check.json` — NVIDIA Warehouse_000 metadata/GT validation and coordinate-frame blocker.

WILDTRACK RGB imagery was not downloaded. The WILDTRACK subset contains only official calibration XML plus 100 annotation JSON files acquired with HTTP byte ranges from the official 6.8 GB EPFL ZIP.
